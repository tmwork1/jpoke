# メガソーラー中のウェザーボールのタイプ確定順序を修正する

## 不具合

特性「メガソーラー」のポケモンが、天候なしで「ウェザーボール」を使用する場合、
ウェザーボールがノーマルタイプとして扱われる。本来はメガソーラーが技使用中に
天候を「はれ」として扱わせるため、ほのおタイプかつ威力2倍になるべきである。

## 原因

`ON_MODIFY_MOVE_TYPE`（ウェザーボールのタイプ変更）が `ON_SETUP_MOVE`
（メガソーラーによる天候の一時上書き）より先に実行されている。

該当経路は2つある。

1. `src/jpoke/core/battle.py` の `Battle._prepare_move_for_query()`
   - `calc_damages()` 等の照会APIで使用される。
2. `src/jpoke/core/move_executor.py` の `MoveExecutor.run_move()`
   - 実際の技実行で使用される。

## 修正方針

両経路で `ON_SETUP_MOVE` を、`ON_MODIFY_MOVE_TYPE` と
`ON_MODIFY_MOVE_CATEGORY` の前に発火させる。

- `ON_TEARDOWN_MOVE` は現在どおり finally 節で必ず発火させ、天候・ハンドラを復元する。
- `MoveExecutor` では `ON_SETUP_MOVE` を成功判定の内側に残さず、タイプ確定の直前へ移動する。
- 既存の `メガソーラー_activate()` / `メガソーラー_deactivate()` のネスト深度・復元判定は変更しない。

## 回帰テスト

以下を少なくともテストする。

1. 天候なし・攻撃側特性メガソーラー・技ウェザーボールで、照会中の `move.type` が `ほのお` になる。
2. 上記でウェザーボールの威力2倍補正が入る。
3. 照会または技実行の終了後、ウェザーボールのタイプは元の `ノーマル`、天候は元の状態へ復元される。
4. 実際の `run_move()` 経路でも同じくほのおタイプになる。
5. 元から雨・砂嵐・雪がある場合も、メガソーラーの技実行中だけ晴れ扱いになり、終了後に元の天候へ戻る。
